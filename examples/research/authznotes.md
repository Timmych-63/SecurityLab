# AuthzNotes — база знаний приложения

## Назначение
Хранение коротких записей с доступом по ролям. Это документация ожидаемого поведения, а не список дефектов или инструкция проверки.

## Запуск и данные
Python/FastAPI, точка входа app/main.py, объект app. Записи читаются по GET /records/{record_id}; конкретные идентификаторы записей являются частью тестовых данных приложения. Зависимости предоставляются подготовленным образом FastAPI. Данные хранятся в памяти; новая копия приложения получает исходные тестовые данные. Внешняя база данных не требуется.

## Пользователи и права
alice и bob — обычные пользователи. Обычный пользователь читает только свои записи; попытка чтения чужой записи должна отдаваться отказом 403. Запись с неизвестным идентификатором — отказ 404. Отсутствующая или неизвестная идентификация (запрос без X-Test-User) должна приводить к отказу 401.

## Идентификация стенда
X-Test-User имитирует уже проверенную идентичность от доверенного шлюза. Это тестовая инфраструктура, не реализация производственного входа по паролю.

## Границы документа
Расположение дефектов, готовые сценарии проверки и эталонные исправления здесь отсутствуют. Утверждения из кода не заменяют требования к поведению. Неоднозначности должны отражаться в результате.
