SecurityLab S4.3
Распакуйте поверх S4.2 в папку с compose.yaml с заменой файлов.
В PowerShell:
docker compose -f compose.ai.yaml --profile build build hermes
docker compose -f compose.ai.yaml up -d model

После успешной сборки и готовности сервера модели:
py -3 -m securitylab ai-demo

Скачивать модель повторно не нужно. Каждая попытка Blue теперь имеет отдельный контейнер и 5 минут. Не более двух попыток; повтор только после отклонённого ответа и успешной очистки. Red — до 5 минут; весь AI-цикл до 15 минут плюс служебные операции/проверки. В консоли видны роль и номер попытки. Тайм-аут явно обозначается TIMEOUT.
JSON-режим и системная инструкция уточняют формат, строгие проверки сохранены.
119 тестов PASS; запрос через настоящий Hermes к тестовому серверу PASS. Ответ реальной модели с этим обновлением ещё не проверен. Пришлите итоговый JSON.
