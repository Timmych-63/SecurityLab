# TicketDesk
Небольшое локальное учебное приложение заявок. Не публиковать в интернете.

Python 3.12, FastAPI 0.115.12, uvicorn 0.34.2. Точка входа app/main.py, ASGI app.main:app.
Данные в памяти, восстанавливаются при каждом запуске. Внешних сервисов и БД нет.

Тестовая идентификация: заголовок X-Test-User (alice, bob, mira, admin). Это замена доверенного шлюза идентификации для изолированного стенда, не реальный вход с паролем. Граница испытания начинается после такого шлюза. Нельзя считать эту схему пригодной для production.

Требования:
- Пользователи alice и bob читают только свои заявки и комментарии к ним.
- Руководитель mira и администратор admin читают все заявки и комментарии.
- Создание заявки доступно всем известным пользователям; владельцем становится автор.
- Изменение статуса доступно только руководителю и администратору.
- Без известного пользователя — 401. Для отсутствующей заявки после идентификации — 404.
- Данные заявки 101 принадлежат alice, 202 — bob.

Маршруты: GET /health; GET /tickets/{id}; GET /tickets/{id}/comments;
POST /tickets с JSON {"title":"..."}; PATCH /tickets/{id} с JSON {"status":"open"|"closed"}.

Запускать в изолированном исполнителе SecurityLab. Зависимости берутся из заранее подготовленного образа FastAPI; приложение не должно само устанавливать пакеты или получать сеть.
