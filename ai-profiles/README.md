# AI-профили оператора

`default` — конфигурация SECURITYLAB_AI_CONFIG, прочитанная при запуске сервера,
или встроенные значения S7.4. `qwen-local` — явный пример TOML для текущей модели.

Для другой установленной модели скопируйте qwen-local.toml в ИМЯ.toml
(латинские буквы, цифры, дефис/подчёркивание), измените model и model_digest вместе.
Digest — ровно 64 шестнадцатеричных символа, без `sha256:`.
Перезагрузите страницу настроек. Выберите новый профиль, проверьте запись и модель.
Контекст 64000..131072, ответ 256..4096, тайм-аут 120..1200 секунд.
Адрес — внутренний Docker DNS, например http://model:11434; сеть — private internal bridge.

Загрузка моделей здесь не выполняется. Файлы не берутся из проверяемого репозитория.
Изменение файла после предпроверки требует новой предпроверки. Активный запуск
сохраняет собственную неизменяемую копию параметров и SHA256 конфигурации.
Неправильный TOML приводит к отказу, а не к подмене профилем по умолчанию.
