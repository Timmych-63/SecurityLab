SecurityLab 0.1.0 — исправление UTF-8 для Windows

Распаковать СОДЕРЖИМОЕ архива поверх папки проекта, содержащей README.md, securitylab и tests.
Разрешить замену файлов. В архиве нет .securitylab и базы данных.
Запустить: py -3 -m unittest discover -s tests -v
Ожидается 38 тестов, на Windows 1 symlink-тест может быть skipped.
Локальная проверка разработчика: 38 PASS на Linux; Windows-повтор ещё требуется.
SecurityLab_UTF8.git.bundle содержит исходники и Git-историю контрольной точки.
