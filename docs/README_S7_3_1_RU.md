# S7.3.1 — ограниченное ожидание локальной модели

Причина: GPU доступен, модель qwen3.5:2b размещена 47% CPU / 53% GPU, контекст 64000. В запуске 01977bf7e3ee4c0a9bb7d3ae922db6a4 baseline и первый кандидат прошли регрессионные 401/404, но утечка осталась; второй Blue был прерван на 300 секундах. Журнал показывает продолжающуюся генерацию около 2.4–2.55 токена/с и 719 токенов к отмене; в данном фрагменте ошибок памяти нет. Успешность неполученного кода неизвестна.

Изменения: только доверенный Hermes worker получает внешний лимит 1200 секунд (20 минут), внутренний run_budget_seconds=1140. Прежние Limits для выполнения проверяемых приложений остаются с максимумом 300 секунд. Лимит вывода 131072 байт и max_tokens=2048 сохранены, максимум два Blue-вызова, инструменты выключены. Длинный лимит не гарантирует правильного ответа и не является новым security verdict. Худший бюджет трёх AI-вызовов — 60 минут плюс служебные операции; обычно завершение раньше.

Hermes данной закреплённой версии требует минимум 64000; эксперимент с 8192 отменён. GPU override обязательно сохранять при запуске model. У пользователя уже есть compose.ai.gpu.yaml; обновление его не заменяет. Новый полноценный S7.3 PASS ещё не получен. Следующий этап после приёмки — переносимость на другом приложении, далее развитие Red/Blue, Dashboard, устойчивость и V1 (см. ROADMAP_V1_RU.md).

Установка поверх S7.3: скопировать securitylab, tests, docs с заменой. Никакие состояния или модели не удалять. В архиве полный bundle для восстановления.

По одной команде из корня проекта:

```powershell
py -3 -m unittest discover -s tests -p 'test_ai*.py' -v
```

Ожидается 32 теста OK. Затем:

```powershell
docker build -f docker/Hermes.Dockerfile -t securitylab-hermes:s4 .
```

После успешной сборки:

```powershell
docker compose -f compose.ai.yaml -f compose.ai.gpu.yaml up -d model
```

И запуск:

```powershell
py -3 -m securitylab --state "$env:TEMP\SecurityLab_S72_DemoState" repo access-ai 2ceb1b1ab21245d8ac979316cf434ed6 --entry app/main.py --policy ".\examples\security_policies\record_ownership_extended.json" --execute
```

В строках Red/Blue теперь timeout 1200 seconds. При отказе отправить summary и соответствующий receipt; не повторять бесконечно. Изменение не ускоряет модель — оно даёт ей ограниченное дополнительное время. Локально 32 теста AI прошли с имитацией Docker/модели; реальная Windows-приёмка этой поправки ожидается.
