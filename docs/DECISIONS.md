# Решения, 2026-11-08

1. Уточняющий промпт дополняет исходное ТЗ: два AI-агента, программный валидатор,
   CLI/HTML/JSON/JSONL. Позднее пользователь вернул Dashboard в план; CS AIReviewer по-прежнему не подключается.
2. Архив M0 не приложен. Новый проект; существующий пользовательский код не менялся.
3. Python 3.11+, stdlib и Git достаточно для первого проверяемого цикла без Docker.
4. SQLite — источник истины; JSONL — экспорт. Это исключает рассинхронизацию двух источников состояния.
5. Встроенный набор проверок одинаков до/после исправления; отсутствие доказательств закрывает путь к FIXED.
6. Отдельный статус находки и задания исключает ошибочную трактовку DONE как «всё исправлено».
7. Локальный запуск разрешён только для побайтно известных встроенных образцов. Произвольный scan заблокирован.
8. Учебный сценарий детерминирован. Нельзя выдавать обнаружение заранее известной ошибки за анализ AI.
9. Один worker на каталог состояния. Повторные запуски ограничены; очередь последовательная.
10. Возврат исправления через revert в учебной ветке, а не reset основной ветки.
11. Hermes-интерфейсы сверены с официальной документацией, но адаптер не объявляется работающим
    до проверки закреплённой версии и реального исполнения. Mock вызов не заменяет такую проверку.
12. Docker runtime отделён от конечного demo-job. Подготовленный Compose не считается итоговым развёртыванием.
13. На слабом ПК не загружаем модели автоматически и не обещаем скорость/вместимость. CPU/GPU benchmark впереди.

14. Актуальное решение пользователя: Dashboard — основной интерфейс, CLI — минимальный
    технический доступ, HTML/JSON — фиксированный результат прогона. Одно ядро и источник данных.
15. S1 предшествует AI: проверяем настройки текущего контейнера; универсальная песочница
    и права Hermes остаются отдельной обязательной работой.
