# S9.1.1 — разделение файла, HTTP-маршрута и пользователя

Исправление поверх установленного S9.1.

Наблюдавшийся ответ Red содержал существующий Python-файл, но вместо HTTP-маршрута модель указала путь файловой системы, а вместо пользователя — unknown. Такой сценарий по-прежнему отклоняется. Изменены подсказка и обратная связь, а не правила допуска.

Что исправлено:
- Отдельные списки допустимых файлов, HTTP-маршрутов и пользователей. Списки не являются готовыми парами тестов.
- Явное различие file (исходный Python-файл), path (маршрут HTTP), actor (существующий пользователь, не название роли).
- Корректирующая попытка получает вычисленные валидатором ошибки предыдущего ответа. Раньше получала только сам предыдущий ответ и общую инструкцию его исправить.
- Предлагается начать с одной обоснованной гипотезы. Лимиты числа сценариев, независимая проверка и правила доступа сохранены.
- Пустой набор гипотез не объявляет приложение безопасным.

Установка:
1. Остановить dashboard, сохранить резервную копию заменяемых файлов.
2. Скопировать содержимое update в корень SecurityLab с заменой.
3. Из корня проекта выполнить:

```powershell
py -3 -m unittest discover -s tests -p "test_discovery.py" -v
docker build -f docker/Hermes.Dockerfile -t securitylab-hermes:s4 .
```

Проверить, что исправленная подсказка находится именно внутри собранного образа:

```powershell
docker run --rm --network none --entrypoint python securitylab-hermes:s4 -c "from securitylab.discovery_contract import retry_errors, selection_fields; print('S9.1.1 READY')"
```

Ожидается `S9.1.1 READY`. Если импорт завершился ошибкой, не повторять AI-запуск — проверить папку сборки и замену файлов.

4. Запустить dashboard с прежним state:

```powershell
py -3 -m securitylab.dashboard --state "$env:TEMP\SecurityLab_S72_DemoState"
```

5. Создать новый запуск TicketDesk с правилами «Поиск сценариев · ticketdesk-discovery». Старый запуск останется отклонённым; его повторно интерпретировать как успешный нельзя.

Контейнер модели оставьте работающим. Заново скачивать модель или менять настройки GPU не требуется. Исходное тестируемое приложение и приватные ответы не меняются.

Проверено: 13 тестов discovery и 37 тестов AI-контрактов/транспорта, включая воспроизведение ошибки пути и unknown, передачу обеих причин в повтор, сохранение отказа для неверного ответа. Живая модель и Docker в этой среде не запускались. Улучшение подсказки не гарантирует, что небольшая модель обязательно предложит корректную гипотезу.
